# jmthon session 
This is the source code for the project [jmthon.deno.dev](jmthon.deno.dev)

The project creates a session code for telegram user bot

The project was divided into branches
- **[go](https://github.com/MOA-YAD/0/tree/go/سيشن%20كود)**: interface and code to creates a session code for telegram in colab
- **[telethon](https://github.com/MOA-YAD/0/blob/telethon)**: Telethon library and extraction code
- **[pyrogram](https://github.com/MOA-YAD/0/tree/pyrogram)**: pyrogram library and extraction code
- **[tgapp](https://github.com/MOA-YAD/0/tree/tgapp)**: Code to extract App-id and api-hash

# jmthon light
This is the source code for the project [jmthon.deno.dev/light](jmthon.deno.dev/light)

The project Runs [jmthon user bot](https://github.com/thejmthon/jmthon) for a few hours on Colab

The project was divided into branches
- **[go](https://github.com/MOA-YAD/0/tree/go/جمثون%20لايت)**: interface and code to run jmthon in colab
- **[lib](https://github.com/MOA-YAD/0/tree/lib)**: The libraries and packages of jmthon light It is stored in a file package.zip
- - It is placed in a file because it is faster than using pip for each library
